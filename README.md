# flex-layout

Web Link: https://karanjthakur.github.io/flex-layout/

Notes Web Site: https://css-tricks.com/snippets/css/a-guide-to-flexbox/

A small demo project illustrating CSS Flexbox layout patterns.

## Overview

This folder contains a minimal example demonstrating flexbox for layout and responsive alignment. It's intended as a lightweight reference for learning and experimenting with flexbox techniques.

## Files

- `index.html` — demo page showing the flex layouts.
- `README.md` — this file.

## How to view

1. Open `index.html` directly in your browser.
2. Or run a simple HTTP server from this directory and open http://localhost:8000:

```bash
python -m http.server 8000
```

## Notes

- No build tools or dependencies required.
- Works offline; recommended to view in a modern browser.
